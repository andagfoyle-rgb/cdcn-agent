# CDCN Agent — User Guide

## What is the CDCN Agent?

The CDCN Agent is an AI assistant built for the Community Development and Carbon Neutral organisation (CDCN), a registered Scottish charity (SC048164). It helps trustees and staff find information in governance documents, track actions, manage deadlines, and prepare for meetings.

All data stays on CDCN's own network — no documents or queries are sent to external services.

## Getting Access

1. Visit the agent at the URL provided by your administrator (e.g., https://cdcnagent.com or your local network address)
2. Click "Create Account" on the login page
3. Fill in your name, email, username, and password (must be 8+ characters with at least one number or symbol)
4. Submit the request — an administrator will review and approve it
5. Once approved, log in with your username and password

## Using the Chat

### Starting a Conversation
- After logging in, you'll see the chat interface
- Type your question in the input box at the bottom and press Enter or click the send button
- The agent will search relevant documents and provide an answer with citations

### Creating Threads
- Click "New Thread" in the sidebar to create a conversation thread
- Threads can be individual (private) or group (shared with other users)
- Add participants to a group thread to collaborate on questions
- Thread history is preserved across sessions

### Example Queries That Work Well
- "What was discussed about the Development Officer in the February 2026 meeting?"
- "Who attended the January 2026 board meeting?"
- "What does the AI Ethics Policy say about data handling?"
- "Summarise the key decisions from the last three board meetings"
- "What funding deadlines are coming up this month?"
- "What are the outstanding action points from the March meeting?"

### Tips for Better Answers
- **Be specific**: "What was the budget decision in the March 2026 meeting?" works better than "Tell me about the budget"
- **Mention dates**: The agent uses dates to find the right documents
- **Name documents**: "What does the Solar PV Report say about costs?" helps the agent find the right source
- **Ask follow-up questions**: The agent remembers your conversation within a session
- **Check citations**: Every answer includes document references in [Document Name, Date, Section] format. If you see [UNVERIFIED], the information couldn't be confirmed from documents

## Feature Pages

### Calendar (/calendar)
- View upcoming events, meetings, and deadlines in a monthly calendar view
- Add new events with title, date, time, and description
- Mark events as completed
- Events from board meeting schedules are automatically populated

### Action Points (/action-points)
- View all action items extracted from meeting minutes
- Filter by status (open, in progress, completed, deferred)
- Track who is responsible and when items are due
- Update status as actions are completed

### Funding (/funding)
- View current funding opportunities scraped from RSS feeds
- See relevance scores, deadlines, and eligibility criteria
- Track the funding pipeline (applications submitted, decisions pending)
- Refresh to check for new opportunities

### Archive (/archive)
- Browse the document archive (governance documents, minutes, policies)
- Upload new documents (staff and admin only)
- Download documents for reference
- Create folders to organise documents

### Memory (/memory)
- View the agent's conversation memory and knowledge
- Search past conversations
- See what the agent has learned from interactions

### Admin Dashboard (/admin)
- Admin-only: manage users, roles, and permissions
- Approve or reject registration requests
- View system statistics and audit logs

## What the Agent Can Do
- Search and summarise governance documents (minutes, policies, reports)
- Answer questions about CDCN's activities, decisions, and finances
- Track action points from meetings
- Manage deadlines and send reminders
- Find relevant funding opportunities
- Draft documents using templates
- Manage a calendar of events
- Support threaded conversations between users

## What the Agent Cannot Do
- Access information outside the document archive
- Make decisions on behalf of trustees or staff
- Send emails or messages to external parties (without explicit setup)
- Guarantee 100% accuracy — always verify important information against source documents
- Work during rest hours (typically 22:00–07:00 UTC)

## Keyboard Shortcuts
- **Enter** — Send message
- **Shift+Enter** — New line in message
- **Escape** — Close modals and menus

## Getting Help
If you encounter issues, contact your CDCN Agent administrator. Common issues:
- "Account locked" — too many failed login attempts; wait 15 minutes
- "Rest mode" — the agent is offline; try again during working hours
- Slow responses — the AI may be processing; wait a moment
