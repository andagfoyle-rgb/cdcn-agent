## 1. Organisation Overview

Community Development Company Nesting (CDCN) is a Scottish charitable organisation and company limited by guarantee, established in 2018 and registered with OSCR (Scottish Charity SC048164). Based in South Nesting, Shetland, CDCN manages the Aald Skül community hub and works to advance community development, heritage, recreation, and relief of need in the Nesting area.

CDCN is entirely volunteer-run at board level, with part-time staff managing the Scrapstore, gym, and administration. The organisation has a track record of delivering community infrastructure projects and has developed an AI assistant ("CDCN Agent") to support its governance, funding, and administrative work. This innovative approach to using technology in a rural community development context demonstrates CDCN's commitment to building organisational capacity and efficiency.

## 2. Project Description

CDCN seeks funding to upgrade its AI infrastructure to host a large language model (LLM) locally, rather than relying on cloud-based API services. The project will acquire and install a high-performance GPU workstation to run capable AI models entirely within CDCN's own premises.

The current AI assistant supports the volunteer-run organisation with governance documents, funding applications, and administrative tasks. However, the present setup relies on an external API-based LLM, which creates ongoing subscription costs of approximately £50–100 per month and raises data security concerns as sensitive organisational documents are processed by an external service. A previous attempt to host a model locally using existing hardware proved too slow and lacked capacity for required tasks.

The proposed solution is a GPU workstation build with dual NVIDIA RTX 4090 graphics cards (providing 48GB combined VRAM), an AMD Ryzen 9 processor, 128GB of RAM, and fast NVMe storage. This configuration can run capable 70B parameter models such as Llama 3.1 70B or Qwen 2.5 72B with quantisation, enabling fast document processing and search across CDCN's indexed archive.

The project will be delivered over four months:
- Month 1: Procurement and delivery
- Month 2: Installation, configuration, model testing
- Month 3: Migration from API to local model, staff training
- Month 4 onwards: Full operation

CDCN will contribute in-kind volunteer time for installation and configuration, plus existing infrastructure including server room space, solar power, and network connectivity.

## 3. Intended Outcomes

- **Data security:** All CDCN governance documents, funding applications, staff records, and community consultation data will be processed entirely within CDCN's own infrastructure, with no data leaving the premises.
- **Cost savings:** Annual savings of £600–1,200 in API subscription costs, eliminating the current £50–100 monthly expenditure.
- **Improved performance:** Faster response times for document drafting and searches, with enhanced capability to process longer documents such as funding applications and trustee reports.
- **Operational resilience:** The AI system will remain functional during internet outages, supported by CDCN's existing solar panels and battery backup.
- **Knowledge sharing:** CDCN will document the project as a demonstrator for other community development trusts considering AI tools, sharing lessons learned and technical specifications.

## 5. Evaluation Approach

CDCN will evaluate project success through quantitative and qualitative measures. Quantitative metrics will include: tracking API subscription cost savings; measuring response times for document generation and search queries; recording system uptime and availability; and documenting the number and length of documents processed.

Qualitative assessment will gather feedback from board members and staff on the AI assistant's effectiveness, accuracy, and usability compared to the previous API-based system. CDCN will also monitor its ability to operate during any internet or power disruptions.

Progress will be documented throughout the four-month implementation period, with a final project report summarising outcomes, lessons learned, and recommendations. This documentation will support CDCN's commitment to sharing knowledge with other community development organisations considering similar AI infrastructure investments.
