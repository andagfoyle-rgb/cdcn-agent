A skill to open, read in full, and edit existing documents from the CDCN archive. This skill addresses the limitation of the search_archive skill, which only returns document fragments. The document_editor skill will: 1) Open a specified document by path from the archive, 2) Extract and present the complete text content, 3) Allow modifications such as reformatting, condensing, amending text while preserving all content, 4) Save modified versions to a designated output location. This is needed for tasks like reformatting a multi-page form to fit on fewer pages, or making amendments to existing templates and policies.
