## 1. Organisation Overview

Community Development Company Nesting (CDCN) is a Scottish charitable organisation (SC048164) and company limited by guarantee (589570), established in 2018. Based at the Aald Skül in South Nesting, Shetland, CDCN serves the local community through the management of facilities including a Scrapstore, gym, growing spaces, and a community hub. The organisation is volunteer-led at board level, with a commitment to innovation in supporting rural community development.

CDCN has developed an AI assistant to support its volunteer-run operations, demonstrating a forward-thinking approach to governance and administration. The organisation seeks to strengthen this capability while ensuring data security and long-term financial sustainability by moving from external cloud-based services to locally-hosted infrastructure.

---

## 2. Project Description

CDCN seeks funding to acquire a high-performance computer system capable of running a large language model (LLM) entirely on-site. The project will enable the organisation's AI assistant to process governance documents, funding applications, and administrative tasks without any data leaving CDCN's premises, eliminating both data security concerns and ongoing cloud API subscription costs.

The proposed solution is an Apple Mac Studio with M2 Ultra processor and 192GB unified memory. This single device can run capable 120B parameter models (such as Falcon 120B or Mistral Large) with quantisation, providing fast inference while keeping all data within CDCN's own infrastructure. The 192GB unified memory provides comfortable overhead for model loading, context windows, and system operations, with 4-bit quantisation requiring approximately 65–70GB and 8-bit quantisation (~120GB) also feasible for higher quality output when needed.

The project will be delivered over four months:

- **Month 1:** Procurement and delivery of hardware
- **Month 2:** Setup, model installation, and testing
- **Month 3:** Migration from API-based service to local model
- **Month 4 onwards:** Full operation

CDCN contributes existing infrastructure including server room space, solar power supply, and network connectivity, along with volunteer time for setup and configuration.

## 3. Intended Outcomes

- All CDCN governance and administrative documents processed entirely on-site, with no data leaving the premises
- Annual savings of £600–£1,200 in API subscription costs, redirecting funds to community benefit
- Faster response times for document drafting, archive searches, and administrative tasks
- Enhanced capability to process longer documents including funding applications and trustee reports
- Improved AI model capability, moving from current 70B parameter limitations to 120B parameter models
- A demonstrator project for other community development trusts considering similar infrastructure

## 5. Evaluation Approach

CDCN will evaluate the project's success through measurable indicators collected during and after implementation. Data collection methods will include:

- **Usage tracking:** Records of documents processed, queries handled, and tasks completed by the local AI system
- **Performance metrics:** Response time comparisons between the previous API-based system and the local model
- **Cost monitoring:** Documentation of savings achieved through elimination of API subscription fees
- **User feedback:** Surveys of board members and volunteers using the system to assess satisfaction and identify improvements

Success will be evidenced by: (1) full migration from API to local processing within three months; (2) verifiable annual cost savings of £600–£1,200; and (3) maintained or improved response times for document drafting and archive searches. CDCN will produce a short case study documenting the project for sharing with other community development trusts.
