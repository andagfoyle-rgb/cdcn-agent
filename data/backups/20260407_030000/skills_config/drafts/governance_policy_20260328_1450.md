## 1. Purpose

This briefing introduces CDCN Agent, an AI assistant designed to support the work of Community Development Company Nesting. The purpose of this document is to explain what CDCN Agent is, how it can help directors in their roles, and how to access and use it effectively. It will be distributed at the CDCN meeting on Tuesday 31st March 2026 at 19:30 at the Aald Skül.

---

## 2. Scope

This briefing applies to all Board Directors of CDCN. It covers the functions, access methods, and limitations of CDCN Agent in supporting organisational activities. It does not cover technical implementation details or system administration.

---

## 3. Definitions

| Term | Definition |
|------|-----------|
| AI Assistant | Software that uses artificial intelligence to help with tasks such as searching documents and drafting text, responding to questions in plain language. |
| CDCN Agent | The specific AI assistant created for Community Development Company Nesting, configured to understand and work with CDCN documents and priorities. |
| Archive | The searchable collection of CDCN documents including minutes, policies, and funding applications that CDCN Agent can access. |

---

## 4. What CDCN Agent Is and Why It Exists

CDCN Agent is an AI assistant built specifically for Community Development Company Nesting. It was created to address four key needs:

4.1 **Reduce administrative burden.** Volunteer directors often spend considerable time on routine tasks such as drafting documents, searching through past records, and preparing meeting materials. CDCN Agent can assist with these tasks, freeing up time for strategic and community-focused work.

4.2 **Improve information access.** Finding information in past minutes, policies, or correspondence can be time-consuming. CDCN Agent can search the archive and provide relevant answers quickly, in plain English.

4.3 **Support funding activities.** Funding applications, reports, and deadlines are central to CDCN's work. CDCN Agent can help draft applications, track deadlines, and identify funding opportunities.

4.4 **Preserve institutional memory.** When directors change or time passes, organisational knowledge can be lost. CDCN Agent maintains accessible records of decisions, policies, and past work, helping continuity.

---

## 5. What CDCN Agent Can Do

CDCN Agent can assist with a range of tasks relevant to CDCN's work. The following table summarises its capabilities.

| Function | Description |
|----------|-------------|
| Search archive | Find information from past minutes, policies, funding applications, and other CDCN documents. |
| Draft documents | Prepare draft minutes, policies, reports, funding applications, agendas, and other organisational documents. |
| Check funding opportunities | Identify and summarise relevant funding opportunities and upcoming deadlines. |
| Manage organisational memory | Store and retrieve key information such as decisions, contacts, and project details. |

## 6. How to Access CDCN Agent

CDCN Agent is available through three access methods. Directors can choose whichever method they find most convenient.

### 6.1 Web Interface

The web interface is available at **www.cdcnagent.com**. Access can be requested directly on the login page. This method provides a full visual interface for interacting with CDCN Agent.

### 6.2 Discord

CDCN Agent is accessible via Discord. Directors who already use Discord can add or access CDCN Agent through the platform.

### 6.3 Telegram

CDCN Agent can also be reached through Telegram. This provides a familiar messaging interface for those who prefer it.

## 7. Practical Examples of Use

The following examples illustrate how directors might use CDCN Agent in practice.

7.1 **"What did we decide about X?"**  
Ask CDCN Agent to search the archive of minutes for information about a past decision, policy, or discussion. For example: "What did we decide about the community defibrillator?" or "When did we last discuss childcare options?"

7.2 **"Draft an agenda for next week's meeting."**  
CDCN Agent can prepare a draft agenda based on recent activities, outstanding actions, and upcoming deadlines.

7.3 **"What funding deadlines are coming up?"**  
CDCN Agent can provide a summary of approaching funding deadlines relevant to CDCN's work.

7.4 **"Summarise our policy on [topic]."**  
Ask CDCN Agent to find and summarise a specific policy or procedure document.

7.5 **"Help me draft a funding application for [project]."**  
CDCN Agent can assist with drafting applications by drawing on past successful applications and relevant organisational information.

## 8. What CDCN Agent Cannot Do

While CDCN Agent is a useful tool, it has important limitations. Directors should be aware of the following:

| Limitation | Explanation |
|------------|-------------|
| Cannot make decisions | CDCN Agent provides information and drafts, but all decisions remain with the Board and individual directors. |
| Cannot replace human judgment | CDCN Agent is a support tool. It does not substitute for the experience, knowledge, and judgment of directors. |
| Cannot access paper-only documents | CDCN Agent can only search documents that have been digitised and added to its archive. Paper records not yet digitised are not accessible. |
| Cannot guarantee accuracy | While CDCN Agent aims to provide accurate information, it is essential that directors verify important details before acting. |
| Cannot browse live websites | CDCN Agent cannot access current information from external websites. It works with the documents already in its archive. |
| Cannot send emails autonomously | CDCN Agent can draft emails or correspondence, but a human must review and send them. |
| Cannot modify source documents | CDCN Agent does not change the original minutes, policies, or other documents in the archive. |
